# project-info

Use this skill to get details about Pilotariak's open-source projects for the Basque pelota sport community.

## Projects

### Frontis — GraphQL API Gateway
- Description: Centralised GraphQL gateway for all Basque pelota data. Unifies five data domains (competitions, clubs, results, categories, disciplines) into a single federated API endpoint.
- GitHub: https://github.com/Pilotariak/frontis
- Page: https://pilotariak.com/frontis

### Kancha — Mobile App (iOS & Android)
- Description: Mobile application for the Basque pelota community. Provides live results, competition calendars, player profiles and phase-by-phase tournament brackets. Available on iPhone and Android.
- GitHub: https://github.com/Pilotariak/kancha
- Page: https://pilotariak.com/kancha

### Xilo — Slack Bot
- Description: Slack bot for the Pilotariak community. Slash commands and real-time events deliver Basque pelota data directly into Slack channels.
- GitHub: https://github.com/Pilotariak/xilo
- Page: https://pilotariak.com/xilo

### Azkena — MCP Server
- Description: Model Context Protocol server for the Pilotariak ecosystem. Exposes Basque pelota data (competitions, results, players, frontons) as MCP tools and resources so AI agents can query the platform directly.
- GitHub: https://github.com/Pilotariak/azkena
- Endpoint: https://pilotariak.com/azkena
