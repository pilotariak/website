# project-info

Use this skill to get details about Pilotariak's open-source projects for the Basque pelota sport community.

## When to use

- The user asks what Pilotariak is, which apps or APIs exist, or where to find the source code.
- You need to pick the right Pilotariak interface: data in code → Frontis, data in an AI assistant → Azkena, results on a phone → Kancha, results in Slack → Xilo.

## Projects

### Frontis — GraphQL API Gateway

- Description: Centralised GraphQL gateway for all Basque pelota data. Unifies five data domains (competitions, clubs, results, categories, specialties) into a single federated API endpoint: https://frontis-gateway.pilotariak.com/graphql (no auth).
- GitHub: https://github.com/Pilotariak/frontis
- Page: https://pilotariak.com/frontis/

### Kancha — Mobile App (iOS & Android)

- Description: Mobile application for the Basque pelota community. Provides live results, competition calendars, player profiles and phase-by-phase tournament brackets. Available on iPhone; Android in development.
- GitHub: https://github.com/Pilotariak/kancha
- Page: https://pilotariak.com/kancha/

### Xilo — Slack Bot

- Description: Slack bot for the Pilotariak community. Slash commands and real-time events deliver Basque pelota data directly into Slack channels.
- GitHub: https://github.com/Pilotariak/xilo
- Page: https://pilotariak.com/xilo/

### Azkena — MCP Server

- Description: Model Context Protocol server for the Pilotariak ecosystem. Exposes Basque pelota data (competitions, clubs, categories, specialties, results) as MCP tools so AI agents can query the platform directly. OAuth 2.1.
- GitHub: https://github.com/Pilotariak/azkena
- Endpoint: https://mcp.pilotariak.com/mcp
